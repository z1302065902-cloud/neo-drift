# NEO DRIFT · 霓虹竞速

第三人称武装赛车网页游戏 — Three.js；多款 GLB 科幻车 + 程序化造型 fallback。

## 启动

```bash
cd neo-race
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765/
```

## 内容

| 类别 | 数量 | 说明 |
|------|------|------|
| 战车 | 8 款 | GLB 真模（概念车/清漆/战损/科幻载具）+ 程序化差异造型 |
| 武器 | 9 种 | 激光三式 / 导弹三式 / 等离子·粒子·离子 |
| 赛道 | 6 环境 | 宇宙、天空、海洋、戈壁、沙漠、霓虹森林（窄弯/危险区/拱门地标） |
| 对手 | 5 AI | 轻松 / 标准 / 地狱 三档难度 |
| 赛制 | 3 圈 | 冲线慢镜 + 本地纪录 / 胜场 |

## 操作

| 平台 | 驾驶 | 氮气 | 开火 | 切武器 | 复位 |
|------|------|------|------|--------|------|
| Mac / PC | WASD / 方向键 | Shift | 空格 / E / F / 鼠标左键 | Q / 右键 / 滚轮 | R |
| 手机 | 虚拟方向键 | 氮气键 | 开火 | 切武器 | — |

## 手感

- 高速转向产生漂移侧倾；氮气有爆发段与回气曲线
- 受击不完全锁死，附带减速恢复
- 天气影响抓地（雨/雹/雷暴）

## 文件

- `index.html` — UI / HUD / 难度 / 首局引导
- `js/main.js` — 驾驶、AI、相机、完赛慢镜
- `js/cars.js` / `cars.procedural.js` / `carLoader.js` — 多 GLB + 程序化
- `js/tracks.js` — 6 赛道 + 动态半宽 + 地标
- `js/weapons.js` — 9 武器 + 冷却/震屏反馈表
- `js/weather.js` — 暴雨 / 冰雹 / 雷暴
- `js/progress.js` — localStorage 纪录
- `js/audio.js` — 引擎 + Track Fury / Racing Rush BGM
- `assets/models/*.glb` — 现成科幻车模（非 AI 生成）
