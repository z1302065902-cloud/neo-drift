# 3D 车模资产

| 文件 | 来源 | 许可 |
|------|------|------|
| `car-concept.glb` | [Khronos glTF CarConcept](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept)（基于 Unity Fan CC0 概念车） | CC BY 4.0 |

8 款车共用此高质量科幻概念车 GLB，运行时按 accent 染色 + 缩放区分。

如需更多车型，可从 Sketchfab **Unity Fan** CC0 Sci-Fi Vehicles 集下载更多 GLB 放入此目录，并在 `js/carLoader.js` 的 `MODEL_MAP` 中映射。
